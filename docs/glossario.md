# Glossário

## 1. Termos de crochê

| pt-BR                | Abrev.  | en-US                     | en-UK                  | Código interno             |
| -------------------- | ------- | ------------------------- | ---------------------- | -------------------------- |
| corrente             | corr    | chain (ch)                | chain (ch)             | `CH`                       |
| ponto baixíssimo     | pbx     | slip stitch (sl st)       | slip stitch (ss)       | `SL`                       |
| ponto baixo          | pb      | single crochet (sc)       | double crochet (dc)    | `SC`                       |
| meio ponto alto      | mpa     | half double crochet (hdc) | half treble (htr)      | `HDC`                      |
| ponto alto           | pa      | double crochet (dc)       | treble (tr)            | `DC`                       |
| ponto alto duplo     | pad     | treble (tr)               | double treble (dtr)    | `TR`                       |
| aumento              | aum     | increase (inc)            | increase (inc)         | `group` de 2               |
| diminuição           | dim     | decrease (dec), sc2tog    | dc2tog                 | `together` sobre 2         |
| diminuição invisível | dim inv | invisible decrease        | invisible decrease     | `together` com `invisible` |
| anel mágico          | am      | magic ring (MR)           | magic ring, magic loop | `start: 'magicRing'`       |
| volta                | V       | round (Rnd)               | round                  | `Row` do tipo `round`      |
| carreira             | C, carr | row                       | row                    | `Row` do tipo `row`        |
| pular                | —       | skip (sk)                 | miss                   | `skip`                     |
| só na alça de trás   | —       | back loop only (BLO)      | back loop only         | `BLO`                      |
| só na alça da frente | —       | front loop only (FLO)     | front loop only        | `FLO`                      |
| arrematar            | —       | fasten off (FO)           | fasten off             | fim da peça                |
| amostra              | —       | gauge                     | tension                | `Gauge`                    |
| receita              | —       | pattern                   | pattern                | `Pattern`                  |
| gráfico              | —       | chart, diagram            | chart                  | saída do pacote `charts`   |
| enchimento           | —       | stuffing                  | stuffing, toy filling  | `finishing.stuffing`       |
| agulha de crochê     | —       | hook                      | hook                   | `hookMm`                   |

A abreviação `pb{k}jun` (por exemplo `pb4jun`) foi adotada na sessão de origem para "k pontos baixos fechados juntos".

## 2. Termos do projeto

| Termo              | Significado                                                                             |
| ------------------ | --------------------------------------------------------------------------------------- |
| Peça               | Parte do amigurumi feita em um trabalho contínuo: cabeça, braço, orelha                 |
| Peça de revolução  | Peça cuja forma é uma curva de perfil girada em torno de um eixo                        |
| Perfil             | Meia silhueta da peça: raio em função da posição ao longo do trabalho                   |
| Polilinha canônica | Perfil com um ponto por volta, com segmentos do tamanho da altura da volta              |
| Topo               | Parte de cima de um ponto, onde se trabalha a volta seguinte                            |
| Topo não contado   | Corrente ou ponto baixíssimo que a receita diz não contar como ponto                    |
| Pai                | Ponto da volta anterior em que um ponto foi trabalhado                                  |
| Grafo de pontos    | Todos os pontos da peça, com a ordem do fio e as ligações a seus pais                   |
| Malha de pontos    | O grafo de pontos com posição 3D                                                        |
| Acoplamento        | Ligação entre os pontos de duas voltas consecutivas                                     |
| Motor direto       | Geometria → receita                                                                     |
| Motor reverso      | Receita → geometria                                                                     |
| Forma canônica     | Representação interna da receita, independente de dialeto                               |
| Dialeto            | Conjunto de termos de uma tradição: pt-BR, US, UK                                       |
| Adaptação          | Diferença, marcada em magenta, entre o que a receita original diz e o que foi desenhado |
| Volta lisa         | Volta só de pontos baixos, sem aumento nem diminuição                                   |
| Contagem amigável  | Total de pontos arredondado para um múltiplo que gera repetições limpas                 |
| Escalonamento      | Deslocar os aumentos de uma volta em relação à anterior                                 |
| Forma de repouso   | Forma calculada sem estiramento                                                         |
| Forma cheia        | Forma calculada com o efeito do enchimento                                              |
